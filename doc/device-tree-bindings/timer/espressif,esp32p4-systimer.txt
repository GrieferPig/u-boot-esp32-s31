Espressif ESP32-P4 System Timer

Required properties:

- compatible: "espressif,esp32p4-systimer"
- reg: controller base address and register size
- clock-frequency: rate of the counter clock in Hz (16000000)

The ESP32-P4 boot stages enable the SYSTIMER clock through HP_SYS_CLKRST.
U-Boot uses the latched 52-bit UNIT0 counter. No timer interrupt is required.
